# NetHackJP `dat/data_jp.base` トールキン引用瀬田貞二訳準拠計画

## 1. 目的と方針
`dat/data_jp.base` に含まれる、Ｊ・Ｒ・Ｒ・トールキン著書の解説・引用テキストについて、評論社より出版されている瀬田貞二氏（および共訳・関連訳者の田中明子氏、山下なるや氏）による公式日本語訳に準拠させます。
これにより、原作小説の美しく厳かな、そしてユーモアに溢れる格調高い文体をゲーム内に再現し、トールキンファン（NetHack プレイヤー）にとって極上の世界観を提供します。

### 翻訳修正ルール:
*   **公式訳の完全再現**: アレンジや意訳を排し、評論社版『指輪物語』『ホビットの冒険』『シルマリルの物語』『終わらざりし物語』のテキストそのものを適用します。
*   **文体の統一**: 瀬田訳特有の「〜です」「〜ます」調（敬体）や、独特の日本語表現（例: `cram` -> 「クラム（乾パンの一種）」、`mumak` -> 「じゅう」、`Elbereth` -> 「星々をちりばめし者、エルベレス」）を正確に再現します。
*   **インデントと折り返し**: 既存のルールに従い、散文は **1行あたり全角30〜34文字（最大34文字）** にて折り返しを行い、詩の形式のものはインデントを維持します。
*   **誤変換の防止**: 助詞の「の」が `of` に誤変換されるバグ等が入らないよう、適用時に細心の注意を払い、`git diff` で徹底的に検証します。

## 3. 段階的適用ステップ（全4グループ）

分量が多いため、混乱を防ぎ、かつ1文字単位の `of` 誤字検証を確実に行うため、以下の4つのグループに分けて順番に適用・検証を行います。

*   **グループ1 (No.1〜7)**: `balrog` 〜 `elvenking`
*   **グループ2 (No.8〜13)**: `elven cloak` 〜 `*mithril*`（未訳箇所を含む）
*   **グループ3 (No.14〜20)**: `mumak*` 〜 `rock mole`（「じゅう」や「オルクリスト」を含む）
*   **グループ4 (No.21〜27)**: `root` 〜 `wraith`（「つらぬき丸」やガンダルフ、ナズグル襲撃など）

## 4. 検証プロセス
1. **ピンポイント置換**: 計画書で定めた瀬田訳等の日本語文に各グループずつ順番に置換。
2. **差分目視確認**: `git diff` により差分を徹底確認。助詞「の」が `of` になっていないこと、インデント崩れがないことを1文字単位でチェック。
3. **ビルドテスト**: `dat/` ディレクトリで `..\tools\Debug\x64\makedefs.exe -d` を実行し、Exit Code 0 で正常終了し、`dat/data_jp` が正しく再構築されることを確認。
4. **ステージング**: 検証完了後、`git add dat/data_jp.base` を実行し保護。
