# NetHackJP 日英両対応入力ガイド

NetHackJP では、ゲーム内の対話入力プロンプトにおいて、英語（ASCII）だけでなく自然な日本語（ひらがな・カタカナ・漢字・全角英数字）での入力にネイティブ対応しています。全角文字は自動的に適切に正規化されて処理されます。

本ドキュメントでは、通常プレイおよびウィザードモード（デバッグ）における日英両対応の入力シーン、具体的な入力例、およびゲーム内の仕様・制約について詳しく解説します。

## 1. 通常プレイでの日英入力シーン

### 1.1 願い (Wish)
魔法のランプ、願いの杖、玉座などで「何をお望みですか？」と問われた際の入力です。

| 項目 | 日本語入力の例 | 英語入力の例 |
| :--- | :--- | :--- |
| **防具・装飾品** | `祝福された+2灰色ドラゴンの鱗鎧`<br>`耐毒の魔除け`<br>`スピードブーツ`（または `スピードの靴`） | `blessed +2 gray dragon scale mail`<br>`amulet versus poison`<br>`speed boots` |
| **道具・ツール** | `祝福された魔法のマーカー`<br>`ユニコーンの角` | `blessed magic marker`<br>`unicorn horn` |
| **複数個のアイテム** | `7本のろうそく`<br>`20本の銀の矢`<br>`2本の充填の巻物` | `7 candles`<br>`20 silver arrows`<br>`2 scrolls of charging` |
| **特殊な状態** | `グレーター・デーモンの死体`<br>`点灯した真鍮のランタン`<br>`金の小像` | `corpse of greater demon`<br>`lit brass lantern`<br>`gold figurine` |

#### 願いの仕様・個数制限についての重要事項
NetHack の通常プレイにおける「願い」では、アイテムのカテゴリによって**入手できる数量に厳格な制限**があります。
- **スタックできないアイテム（道具・武器・防具・杖など）**:
  魔法のマーカー、剣、鎧などは、どれほど大きな数字（例: 「7個の魔法のマーカー」）を指定して願っても、**必ず1個しか手に入りません**。チャージ数や耐久度の最大値を狙う場合は、数量ではなく `祝福された魔法のマーカー` のように祝福状態を指定するのが現実的です。
- **スタック可能なアイテム（ろうそく・弾薬・巻物・ポーションなど）**:
  - **ろうそく**: 最大で **7個** まで（イェンダーの祈祷の儀式に必要な個数）。
  - **投射武器・弾薬・石（矢、ダーツ、スリングの石等）**: 最大で **20個** まで。
  - **巻物・ポーション・食料など**: ランダム制限（`d.cnt < rnd(6)`）が適用されるため、通常は **2〜3個** が上限となります。

#### 願いの文法ヘルプ画面
「何をお望みですか？」のプロンプトで以下の単語を入力すると、願いの書き方や指定できるキーワードのヘルプ画面をいつでも参照できます（願いの機会は消費されません）。
- **日本語**: `ヘルプ` または `たすけて`
- **英語**: `help` または `?`

### 1.2 虐殺 (Genocide)
虐殺の巻物を読んだ際などに「何を虐殺しますか?」と問われた時の入力です。

| 指定タイプ | 日本語入力の例 | 英語入力の例 | 補足 |
| :--- | :--- | :--- | :--- |
| **単体虐殺（種族名）** | `マスター・リッチ`<br>`銀色ドラゴン`<br>`マインド・フレア` | `master lich`<br>`silver dragon`<br>`mind flayer` | 指定した特定のモンスター種族を根絶します。 |
| **クラス虐殺（シンボル記号）** | `L`<br>`h`<br>`;` | `L`<br>`h`<br>`;` | 祝福された虐殺の巻物で、そのシンボルに属するモンスター群を一括虐殺します。 |
| **虐殺の拒否（誓いの維持）** | `none` または `nothing`<br>`なし`<br>`（空入力でEnter）` | `none`<br>`nothing`<br>`(empty string)` | 不虐殺の誓い（Genocide conduct）を継続する場合、これらを入力して虐殺を安全に辞退できます。 |

### 1.3 自己変身 (Polymorph)
「自己変身の制御（Polymorph control）」能力を持った状態で変身の罠を踏んだり、変身の薬・杖・魔法を使った際の入力です。

| 指定タイプ | 日本語入力の例 | 英語入力の例 | 補足 |
| :--- | :--- | :--- | :--- |
| **モンスター種族名** | `銀色ドラゴン`<br>`マスター・リッチ`<br>`吸血鬼の貴族` | `silver dragon`<br>`master lich`<br>`vampire lord` | 任意の通常モンスターを指定して変身します。 |
| **モンスタークラス名** | `ドラゴン`<br>`オーク` | `dragon`<br>`orc` | 種族ではなく大分類名を指定した場合、そのクラスの中からランダムに変身します。 |
| **ランダム指定** | `ランダム` または `*` | `random` または `*` | 制御変身を放棄し、完全ランダムに変身します。 |
| **変身の中止** | `ESC` キー | `ESC` key | 変身をキャンセルします。 |

### 1.4 魔法のマーカーでの書き込み (Write)
魔法のマーカーを適用（`#apply`）して、白紙の巻物や白紙の魔法書（呪文書）に文字を書き込む際の入力です。

| 対象 | 日本語入力の例 | 英語入力の例 | 補足 |
| :--- | :--- | :--- | :--- |
| **巻物の正式名** | `識別` または `識別の巻物`<br>`解呪` または `解呪の巻物`<br>`虐殺` または `虐殺の巻物`<br>`鑑定`（JNetHack互換） | `identify` または `scroll of identify`<br>`remove curse`<br>`genocide` | すでに識別済みの巻物を書き込みます。「〜の巻物」を省いた名前やJNetHack慣用句でも認識します。 |
| **巻物の未識別ラベル** | `コンテキスト・スイッチ`<br>`アンドロメダの銀河` | `ELBIB YLOH`<br>`TEMOV` | 現在のゲームでそのラベルに割り当てられている巻物が書き込まれます。 |
| **巻物のプレイヤー呼称** | `ふつうの巻物`（名付けたcall名） | `scroll called plain` | プレイヤーが `#name` で種類に付けた呼称（call名）でも指定可能です。 |
| **魔法書（呪文書）** | `魔力の矢の呪文書`<br>`解呪の魔法書`<br>`穴掘り` | `spellbook of force bolt`<br>`remove curse`<br>`dig` | 魔法書は「呪文書」「魔法書」どちらの接頭・接尾辞でも認識します（※未識別外見ラベルでの書き込みは不可で、識別済みの名前が必要です）。 |

### 1.5 階層テレポート (Level Teleport)
階層テレポートの巻物、トラップ、または能力を使用して別の階層へ移動する際の入力です。

| 指定タイプ | 日本語入力の例 | 英語入力の例 | 補足 |
| :--- | :--- | :--- | :--- |
| **絶対階層指定** | `5`（現在ダンジョンの5階へ） | `5` | 単純な数値を入力すると、その深さの階層へジャンプします。 |
| **相対階層指定** | `+2`（2階下へ）<br>`-1`（1階上へ） | `+2`<br>`-1` | 符号付き数値を入力すると、現在階からの相対移動となります。 |
| **方向・ランダム記号** | `>`（下の階へ）<br>`<`（上の階へ）<br>`*`（ランダム階層へ） | `>`<br>`<`<br>`*` | 階段と同じ記号で直前・直後の階へ、`*` でランダム階層へ移動します。 |
| **特殊階層・ブランチ名** | `鉱山` または `ノームの鉱山`<br>`倉庫番`<br>`神託所` または `デルフィ`<br>`城`<br>`死者の谷` | `mines`<br>`sokoban`<br>`oracle` または `delphi`<br>`castle`<br>`valley` | **同一ブランチ内で過去に訪問済みの階層・分岐**を指定できます（未訪問の階層には通常プレイでは飛べません）。 |
| **プレイヤーのカスタム注釈** | `拠点`<br>`寺院`<br>`ショップ` | `stash`<br>`temple`<br>`shops` | プレイヤーが `#annotate` で設定した注釈名を指定して、その階層へ直接テレポートできます。 |

### 1.6 金庫番からの誰何・名乗り (Vault Guard Challenge)
迷宮内の宝物庫（Vault）にテレポートなどで侵入した際、番兵（金庫番）が現れて「見知らぬ者よ、名を名乗れ. -」と問いかけてきた時の名乗り入力です。

| 名乗り | 日本語入力の例 | 英語入力の例 | 結果・効果 |
| :--- | :--- | :--- | :--- |
| **金庫番を欺く合言葉** | `クロイソス`<br>`クレオソート` | `Croesus`<br>`Kroisos`<br>`Creosote` | 大富豪クロイソス本人、またはパロディキャラクター（クレオソート）の名を名乗ると、金庫番は騙されて会釈し、平和裏に立ち去ります。 |
| **自分の名前** | `（キャラクター作成時の名前）` | `(Player character name)` | 自分の正規の名前を名乗ると、金庫番から宝物庫の外へ退去するよう先導されます。 |
| **その他・偽名** | `（適当な名前や嘘の名前）` | `(Any fake name)` | 金庫番を欺けず、先導または敵対行動に移ります。<br>※**秩序属性のキャラクターへの注意**: 自分の名前以外を答えると「嘘つき（Liar!）」とみなされ、**アライメント値（属性値）が -1 ペナルティ**を受けます。 |

### 1.13 キャラクター作成時の名前入力
ゲーム開始時、主人公キャラクターの名前を決定するプロンプトです。

- **入力例**: `風来のシレン`, `アリス`, `武蔵`, `Shiren`, `Alice`
- 漢字・ひらがな・カタカナ・英数字いずれもフルサポートされています。

### 1.14 神殿・祭壇への寄進・奉納金 (Donate / Bribe)
寺院の神官（僧侶）に話しかけたり、特定の悪魔への賄賂の際に金額を入力するプロンプトです（例: `いくら寄進しますか?`）。
- **入力例**: `400`, `５００`, `1000`
- 全角数字（`５００` など）を入力した場合でも自動的に半角に正規化されて正しく認識されます（※全角入力による 0 判定で神官が激怒する罠が防止されています）。
- `ESC` キーで寄進を取りやめることができます。

---

### 1.15 城の跳ね橋の開閉旋律 (Gear Melody / Pass-tune)
ホルンや木製フルートなどの楽器を適用（`#apply`）して城の跳ね橋を開閉する合言葉旋律（5音の音列）を入力するシーンです。
- **入力例**: `ABCDE`, `ｃｄｅｆｇ`, `ＡＢＣＤＥ`
- A〜G の音列を大文字・小文字、半角・全角問わず入力可能です。

---

### 1.16 危険行動の確認 (Paranoid Confirm)
`paranoid_confirmation` 設定が有効な環境で、水没・溶岩への進入、攻撃、アイテムの破壊など危険な行動を行う際に要求される確認プロンプトです（例: `本当に〜しますか? [yes/no]`）。
- **肯定の入力例**: `yes`, `ｙｅｓ`, `はい`
- **否定・中止の入力例**: `no`, `ｎｏ`, `いいえ`, `やめる`, `中止`, `ESC`（取り消し）、またはそのまま `Enter`
- 誤操作による死亡を防ぐため、完全な単語入力のみを肯定として受け付け、全角や日本語の「はい」も安全に利用できます。

---

### 1.17 所持品アイテムの文字選択 (Inventory Selection)
所持品から使用するアイテムを選ぶ際、文字（アルファベット）を入力するプロンプトです（例: `どれを選択しますか? [a-z]`）。
- **入力例**: `a`, `ｂ`, `ｍ`（メニュー表示）, `？`（一覧表示）
- 全角アルファベットや全角記号（`？` や `＊`）も自動的に半角へ正規化されて認識されます。

---

### 1.18 ステータス行のハイライト閾値設定 (Status Highlight Threshold)
`#statuslines` 設定画面や設定オプションにおいて、HPやMP、満腹度などのステータス警告カラーを切り替える閾値を設定する入力です。
- **入力例**: `<50%`, `＜５０％`, `=10`, `＞＝２０`
- 全角の比較演算子（`＜`, `＞`, `＝`）や全角数字、全角パーセント（`％`）も半角に自動正規化されます。

---

## 2. ウィザードモード（デバッグ）専用の入力シーン

デバッグモード（`-D` オプション付き起動など）において利用可能なコマンドの入力シーンです。

### 2.1 階層テレポート (#wizlevelport)
全ダンジョンのあらゆる階層へ即座に移動できるコマンドです。

| 指定タイプ | 日本語入力の例 | 英語入力の例 | 補足 |
| :--- | :--- | :--- | :--- |
| **特殊階層名** | `アストラル界`<br>`モーロックの聖域`<br>`死者の谷`<br>`城`<br>`ローディオス砦`<br>`ヴラドの塔` | `astral`<br>`sanctum`<br>`valley`<br>`castle`<br>`fort`<br>`vlad` | 未訪問であっても、目的の階層へ直接テレポートできます。 |
| **クエスト階短縮指定**<br>（★最新仕様） | `locate`<br>`goal`<br>`start`<br>`quest-1` | `locate`<br>`goal`<br>`start`<br>`quest-1` | 役割プレフィックス（`val-` 等）を省略した部分一致検索に対応しており、クエストの各階層へ簡単にジャンプできます。 |
| **全階層選択メニュー** | `?` | `?` | ダンジョン内の全ブランチおよび全階層が一覧メニューで表示され、対話的に選択できます。 |

---

### 2.2 アイテム生成 (#wish / Debug Wish)
制限のない自由なアイテム生成です。通常プレイと異なり、道具の複数個生成や強化値の制限解除、任意のアーティファクトの生成が可能です。
- **入力例**: `7個の魔法のマーカー`, `祝福された+7虐殺の巻物`, `7 magic markers`, `blessed +7 scroll of genocide`

---

### 2.3 モンスター召喚 (#wizgenesis)
指定した任意のモンスターをその場で生成します。
- **入力例**: `銀色ドラゴン`, `マスター・リッチ`, `*`（ランダム）, `silver dragon`, `master lich`

---

### 2.4 自由変身 (#polyself)
通常は変身が禁止されている種族（人間、NPC、ショップ店主、神官など）も含め、あらゆる存在に変身します。
- **入力例**: `長老`, `ショップ店主`, `クロイソス`, `aligned priest`, `shopkeeper`, `Croesus`

---

### 2.5 玉座の効果指定 (#sit)
玉座に座った際に発生するイベント効果（全13種類）を任意に選んで発生させます。
- **入力例**: `1` 〜 `13`, `0`（ランダム）

---

### 2.6 経験レベル変更 (#level)
主人公の経験レベルを直接指定値に変更します。
- **入力例**: `1` 〜 `30`

---

### 2.7 Luaスクリプト実行 (#wizlua / #wizdes)
外部の Lua スクリプトファイルやダンジョン定義（des）ファイルを動的に読み込んで実行します。
- **入力例**: `test.lua`, `special_level.des`

---

### 2.8 特定モンスターの生成 (create_particular)
ウィザードモードで特定のモンスター種族またはクラスを指定して召喚する際のプロンプトです。
- **入力例**: `銀色ドラゴン`, `silver dragon`, `L`（リッチ類）, `＊`（ランダム）
- 全角文字（全角シンボルや全角モンスター名）も自動的に正規化されて認識されます。

---

### 2.9 変身形態の強制指定 (#wizforcechameleon)
カメレオンやドッペルゲンガーの変身先モンスターを指定するデバッグコマンドです。
- **入力例**: `銀色ドラゴン`, `silver dragon`, `d`（犬類）, `ランダム`, `random`, `*`
- 日本語の「ランダム」や全角記号も完全に対応しています。
