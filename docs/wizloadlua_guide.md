# #wizloadlua でできること（NetHack Luaデバッグ機能解説）

NetHack（バージョン3.7以降）では、デバッグモード（開発者モード）中に `#wizloadlua` コマンドを使用することで、任意のLuaスクリプトファイルを読み込んで実行することができます。この機能は、[wizcmds.c](../src/wizcmds.c#L353-L374) の [wiz_load_lua](../src/wizcmds.c#L353-L374) 関数によって実装されており、ゲーム内のさまざまな状態をプログラムから動的に取得・操作することが可能です。

以下に、Luaスクリプトを介して操作できる主な機能とAPIについて詳しく解説します。

---

## 1. プレイヤーキャラクター (`u` テーブル) の操作と取得

グローバルテーブル `u` を通じて、プレイヤーキャラクターの状態取得や一部の操作が可能です。

### プレイヤー情報の取得
*   `u.ux`, `u.uy` : プレイヤーの現在座標 (x, y)
*   `u.uhp`, `u.uhpmax` : 現在HPと最大HP
*   `u.uen`, `u.uenmax` : 現在魔力と最大魔力
*   `u.ulevel`, `u.ulevelmax` : 経験レベルと最大経験レベル
*   `u.uhunger` : 空腹度
*   `u.uluck` : 運 (Luck)
*   `u.role` : 職業名（文字列）
*   `u.moves` : 経過ターン数
*   `u.dlevel`, `u.dnum` : 現在の階層番号とダンジョン番号
*   `u.depth` : 現在の階層の深さ
*   `u.inventory` : プレイヤーの所持品オブジェクト（アイテムチェーンの先頭）
*   `u.uhave_amulet` : イェンダーの魔除けを所持しているか
*   `u.invocation_level` : 呼び出しの儀式を行う階層かどうか

### プレイヤーに対する操作
*   `u.giveobj(obj)` : 指定したアイテムオブジェクトをプレイヤーのインベントリに追加します。
*   `u.clear_inventory()` : プレイヤーの所持品をすべて消去します。

---

## 2. アイテム (`obj` クラス) の生成と操作

アイテムを扱う [nhlobj.c](../src/nhlobj.c) をベースに、Luaから柔軟にアイテムの生成やパラメータ変更、配置が行えます。

### アイテムの生成
*   `obj.new("アイテム名")` : 願ったときと同じ名前解析処理を使って、新しいアイテムオブジェクトを作成します（例: `obj.new("blessed +3 rustproof long sword")`）。
*   `obj.new({ id = "アイテムID", class = "クラス記号" })` : IDやクラス記号を指定して直接生成します。

### マップ上・インベントリ内のアイテム操作
*   `obj.at(x, y)` : マップ上の座標 (x, y) に存在する最上部のアイテムを取得します。
*   `obj.next()` / `an_obj:next(use_nexthere)` : マップ上やインベントリ内のアイテムチェーンをたどって次のアイテムを取得します。
*   `an_obj:placeobj(x, y)` : 指定した座標のマップ上にアイテムを配置します。
*   `an_obj:bury(x, y)` : アイテムを地面に埋めます。

### コンテナ（箱や袋）の操作
*   `an_obj:container()` : アイテムが入っているコンテナ（箱など）を取得します。
*   `an_obj:contents()` : コンテナに入っているアイテムチェーンの先頭を取得します。
*   `an_obj:addcontent(other_obj)` : コンテナの中に他のアイテムを入れます。

### アイテム情報のダンプ・特性取得
*   `an_obj:totable()` : アイテムの状態フラグ（呪い/祝福状態、強化値、材質、数量、名前など）をまとめた Lua テーブルを取得します。
*   `an_obj:class()` または `obj.class(otyp)` : 重量、基本価格、ダメージ値、材質など、NetHackの定義データ（`objects` 配列）に基づく静的な特性情報を取得します。

---

## 3. マップ情報の取得 (`nh` テーブルの機能)

マップやダンジョンの地形、階段などの情報を取得することができます（[nhlua.c](../src/nhlua.c)）。

*   `nh.getmap(x, y)` : 指定座標のセル情報を取得します。戻り値は以下のような情報を含むテーブルです：
    *   `typ_name` : 地形タイプ名（`"room"`, `"corr"`, `"wall"` など）
    *   `mapchr` : 画面に表示される文字（`.`, `#` など）
    *   `lit` / `waslit` : 明るさの状態（boolean）
    *   `has_trap` : トラップの有無（boolean）
    *   `flags` : ドアの開閉・施錠状態、祭壇の属性、噴水やシンクのフラグなど
*   `nh.stairways()` : 現在のレベルに存在するすべての階段とハシゴの一覧（座標、上り/下り、接続先のダンジョン）を取得します。
*   `nh.flip_level(mode)` : レベルのマップを反転（縦、横、または両方）させます。

---

## 4. トラップとタイマーの操作
*   `nh.gettrap(x, y)` : 座標 (x, y) にあるトラップ情報を取得します。
*   `nh.deltrap(x, y)` : 座標 (x, y) にあるトラップを消去します。
*   `nh.start_timer_at(x, y, "melt-ice", turns)` : マップ上にタイマーを設置します（例: 氷が溶けるまでのターン数など）。
*   `an_obj:start_timer("hatch-egg", turns)` : アイテムに対してタイマーを設置します（例: 卵が孵化するまでのターン数など）。`peek_timer` や `stop_timer` もあります。

---

## 5. デバッグ制御・シミュレーション (`nh` テーブルの機能)

テストプレイの自動化や、デバッグを有利に進めるためのシステム制御関数です。

### デバッグフラグの制御
`nh.debug_flags(table)` を使うことで、ゲームシステムの一部の処理を動的に無効化・制御できます。
*   `mongen = false` : モンスターの自然生成を無効化します（同時に、マップ上に存在するすべてのモンスターを消去します）。
*   `hunger = false` : プレイヤーの空腹度の進行を停止します。
*   `overwrite_stairs = true` : 階段の上書き生成を許可します。
*   `prevent_pline = true` : メッセージ表示 (`pline`) をUIへ送信しないようにします（自動テスト中のノイズ軽減に便利です）。

### キー入力とターンの進行
*   `nh.pushkey("keys")` : 指定したキー入力をコマンドキューに送信します。
*   `nh.doturn(domulti)` : ゲームを1ターン（または `multi` による複数アクションが完了するまで）進行させます。

### ゲーム状態のクイック保存と復元（チュートリアル用機能）
*   `nh.gamestate()` : 現在のターン数、インベントリ、満腹度、属性値、討伐データ等の状態をメモリ上に一時保存します。
*   `nh.gamestate(true)` : 一時保存した状態へ復元します。

---

## 6. マップの範囲選択・作成 (`selection` クラス)

[nhlsel.c](../src/nhlsel.c) で定義されている `selection` クラスを使用すると、マップ作成時のように特定の領域（部屋全体、円形、矩形、あるいは floodfill による特定地形領域）を選択し、論理演算（AND, OR, XOR, NOTなど）で選択範囲を合成して操作することができます。

---

## 具体的な使用例 (Luaスクリプトのサンプル)

たとえば、以下のようなスクリプトを用意して `#wizloadlua` で読み込むことで、デバッグ検証作業を効率化できます。

### 例1: 祝福された無力化の薬と魔除けをインベントリに加える
```lua
-- アイテムを生成
local potion = obj.new("blessed potion of gain level")
local amulet = obj.new("blessed amulet of life saving")

-- プレイヤーのインベントリに与える
u.giveobj(potion)
u.giveobj(amulet)

nh.pline("デバッグ用アイテムをインベントリに追加しました！")
```

### 例2: モンスターの自然生成と空腹度を停止し、HPと魔力を全回復する
```lua
-- 空腹とモンスター生成を停止
nh.debug_flags({ hunger = false, mongen = false })

-- プレイヤー情報を出力しつつ、HPとEnを全回復
nh.pline("現在位置: " .. u.ux .. ", " .. u.uy)
nh.pline("現在のHP: " .. u.uhp)

-- #panic コマンドの実装などを利用して回復、あるいはデバッグモードの機能と併用します
```
