## 表記ルール
- `%` プレースホルダ（`%p`, `%d`, `%l`, `%n`, `%o` など）は改変しない。
- Luaキー名・テーブル構造・配列順は変更しない。
- 口調は叙事調（常体）を基本とし、役職メッセージの命令調は原文ニュアンスを維持する。
- 既存UI訳語に合わせる（例: 職業名・種族名）。

## 作業ルール
- 反映はブロック単位で行う（common → 各職業）。
- 1回の変更量を抑え、都度ビルド確認する。
- 既存英文を削除しない（文字列置換のみ）。
