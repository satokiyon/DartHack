## 3. Quest 翻訳の実務知見

- **Lua 構造の維持**: キー名、テーブル構造、配列順は変更しない。
- **プレースホルダ**: `%p`, `%d`, `%l`, `%n`, `%o` などのプレースホルダは、`quest.lua` 独自の展開ルールがあるため、順序や個数を変えない。
- **口調の使い分け**:
  - 地の文は叙事調（常体）を基本とする。
  - 地の文では主語「あなた」を必要な場合に限り、自然な箇所では省く。
  - NPCの呼びかけは「お前」を基本とする。神格・儀礼的な台詞や、原文で明確に敬意・格式がある話者は「そなた」などを例外として使う。
  - 役職メッセージや神託などの命令調は、原文の威厳やニュアンスを維持する。
- **職業ごとの声**: 原文の設定に基づいて語彙や調子を変えるが、職業イメージだけで性格・設定を作り足さない。
  - 考古学者: 大学・発掘・研究の語彙と学者らしい皮肉。
  - 野蛮人: 部族・戦士・戦利品に根ざした率直な話し方。
  - 洞窟人: 祖先・洞窟・幻視の旅に結びついた素朴で神話的な語り。
  - 治療師: 古典医学の語彙、診療の実務、病気にまつわる冗談。
  - 騎士: 騎士道・宮廷・忠誠を反映した格式ある語り。
  - 武闘家: 修行・瞑想・教団の戒律を軸にした落ち着いた語り。
  - 司祭: 信仰・祭壇・教団の規律を重視した敬虔な語り。
  - レンジャー: 森林・野外行動・隠密に関する実用的な語彙。
  - 盗賊: 取引・獲物・会費を語る親分の皮肉と盗賊仲間の俗な冗談。
  - 侍: 武士道・名誉・帝への忠義を軸にした簡潔で格式ある語り。
  - 観光客: 旅程・宿・土産にまつわる現代的な旅行者のユーモア。
  - ワルキューレ: ヴァルハラ・ラグナロク・運命の予言を帯びた戦士の語り。
  - 魔法使い: 秘術・研究・予言を語る老練な師の調子。
- **代名詞マクロ**: 主格 `%nh` 系は「彼/彼女/それ」、目的格 `%ni` 系は「彼を/彼女を/それを」、所有格 `%nj` 系は「彼の/彼女の/その」を展開する。含まれる助詞を重ねず、展開後の文で自然な助詞・語順になるよう文型を組み替える。
- **同胞・家族マクロ**: `%s` は性別を問わず「同胞」、`%S` は既存仕様どおり「息子／娘」とする。`%sp` で複数を表す場合は、必要に応じて文面側に「たち」を補う。実際の家族は文脈に応じて「家族」等に書き換え、敵の `little %s` のような罵りは「若造」等の自然な語にする。
- **知覚マクロ**: `%x` は視界に応じて「見る/感じる」を返す。盲目時も日本語として自然に成立する述語につなげる。
- **反映ルール**: 反映はブロック単位（common → 各職業）で行い、都度ビルド確認することを推奨。
- **非破壊編集**: 原文の英文を削除せず、文字列リテラル部分のみを置換すること。
