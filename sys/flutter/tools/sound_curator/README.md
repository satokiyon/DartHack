# NetHack 5.0 / DartHack サウンドキュレーター (Sound Curator)

本ツールは、『[sound_macros_list.md](../../doc/sound_macros_list.md)』に定義されている **全 274 種類の効果音・実績音・楽器演奏音・声音** を、効率よく・高品質かつ狙い通りに収集・選定・正規化・管理するためのローカルWebワークスペースです。

---

## 主な機能と特徴

1. **進捗ダッシュボード & カテゴリフィルタ**:
   - 全274音の収集進捗率（パーセンテージ）をリアルタイム表示。
   - 「未設定のみ」「確定済のみ」「効果音(197)」「実績(23)」「楽器(47)」「声音(7)」による瞬時絞り込み。
   - サウンドIDや日本語説明文によるインクリメンタル検索。
2. **ワンクリック外部検索支援（全 13 サイト対応）**:
   - 各カード内に色分けされたコンパクトバッジが配置され、ワンクリックで該当サイトの検索結果へジャンプできます。
   - **🇯🇵 国内フリー音源サイト (8件)**:
     - **効果音ラボ**：日本最大手の効果音サイト（商用フリー・クレジット不要）
     - **On-Jin ～音人～**：老舗ゲーム効果音サイト（実音系が充実・クレジット表記）
     - **OtoLogic**：ゲーム開発定番・超高品質（CC BY 4.0）
     - **効果音辞典**：効果音ラボ姉妹サイト（完全フリー・クレジット不要）
     - **Springin' Sound Stock**：アプリ/ゲーム向け効果音（クレジット不要）
     - **魔王魂**：RPG戦闘・魔法・システム音の定番（クレジット表記）
     - **ポケットサウンド**：レトロ・ファンタジー系素材（クレジット表記）
     - **甘茶の音楽工房**：実績ファンファーレ・ジングル向けフリーBGM
   - **🌐 海外・オープン素材サイト (5件)**:
     - **Pixabay**：世界的素材サイトの膨大な効果音ライブラリ（商用可・クレジット不要）
     - **SoundDino**：海外の高品質フリー効果音・打撃/環境/UI（ロイヤリティフリー）
     - **Freesound.org**：オープンライセンス（CC0/CC-BY）の世界的アーカイブ
     - **ZapSplat**：世界最大級10万点以上のプロ向けフリー効果音（クレジット表記）
     - **OpenGameArt.org**：オープンソースゲーム開発向け総合素材ライブラリ
3. **ドラッグ＆ドロップによる即時登録 & 自動正規化 (ffmpeg)**:
   - ダウンロードした音声ファイル（WAV, MP3, OGG, FLAC等）を該当カードにドラッグ＆ドロップするだけで即時取り込み。
   - モーダルで出典（サイト名、作者、URL、ライセンス）を入力して「確定」を押すと、バックグラウンドで `ffmpeg` が自動実行されます：
     - **先頭無音の自動ミリ秒トリム**（即座に発音させるための最適化）
     - **EBU R128 ラウドネス正規化 (-14 LUFS / True Peak -1.0dBFS)**（音量差による爆音・蚊の音を完全解消）
     - **Ogg Opus (48kHz)** への高品質・軽量エンコード
     - 出力先: `sys/flutter/assets/sounds/<filename>.ogg`
4. **楽器音 47 種の完全自動サンプリング**:
   - オープンSoundFont（FluidR3 GM）と FluidSynth を用いて、木製フルート・角笛・ラッパ・ハープ等のA〜G音階（計47ファイル）を正確なピッチと音色で一括自動生成済み。
5. **ライセンス一覧（`attributions.txt`）の自動生成**:
   - 採否と同時に `sys/flutter/assets/sounds/attributions.txt` に作者、出典URL、ライセンス条件が本家フォーマット準拠で自動記録・更新されます。

## 起動方法

### 方法 A: PowerShell スクリプト（推奨）
```powershell
powershell -ExecutionPolicy Bypass -File sys/flutter/tools/sound_curator/run_curator.ps1
```
サーバーが立ち上がり、既定のブラウザで `http://localhost:8765` が自動的に開きます。

### 方法 B: 手動起動
```powershell
python sys/flutter/tools/sound_curator/server.py
```
ブラウザで `http://localhost:8765` にアクセスしてください。

## 推奨キュレーションワークフロー

1. ブラウザで画面を開き、上部の **「⏳ 未設定のみ」** フィルタをクリック。
2. 収集したい効果音カードのボタン（例: **［🟧 効果音ラボで検索］** や **［🟦 Freesoundで検索］**）をクリック。
3. ブラウザで目的の音源（WAVやMP3）をダウンロード。
4. ダウンロードしたファイルをカードの「📥 ドロップゾーン」にドラッグ＆ドロップ。
5. モーダルで「出典サイト」「作者」「URL」「ライセンス」を確認し、**「正規化 & 確定 (Opus変換)」** ボタンをクリック。
6. 自動的に Opus 変換され、確定済みカードに切り替わり、試聴プレイヤーで仕上がりを確認できます。
